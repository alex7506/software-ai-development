# AI-CONTEXT — TaskFlow

## Source of truth
Los requisitos, arquitectura, tecnología, tareas, validaciones y decisiones persistentes del proyecto.

## Current state
- Phase: BOOTSTRAPPING / transición a DEVELOPMENT
- Technology: Google ecosystem
- Frontend: Next.js
- Auth: Firebase Authentication
- Data: Cloud Firestore
- Authorization: Firebase Security Rules
- Deployment: Firebase App Hosting

## Scope
Auth, CRUD de tareas, estado, prioridad, fecha, filtros, dashboard, persistencia, pruebas, seguridad y despliegue.

## Out of scope
Colaboración, equipos, chat, comentarios, archivos, subtareas, notificaciones avanzadas, móvil nativo, IA de productividad, calendarios externos, billing y marketplace.

## Rule
No añadir funcionalidad ni tecnología sin requisito o cambio aprobado.

# Technology Profile — Google Ecosystem

Perfil de referencia, no obligatorio.

- Frontend: Next.js
- Authentication: Firebase Authentication
- Data: Cloud Firestore
- Authorization: Firebase Security Rules
- Backend: Next.js; Cloud Functions for Firebase solo cuando exista una necesidad justificada
- Deployment: Firebase App Hosting
- Cloud: Google Cloud
- AI: Gemini / Google AI Studio cuando una tarea lo requiera
- Git: repositorio Git remoto

No se incorporan servicios de Google automáticamente. Gemini no se convierte en funcionalidad del producto sin un requisito aprobado.

# Technology Profile — Generic

Este perfil describe tecnologías aprobadas para un proyecto sin convertirlas en parte de la metodología.

## Reglas
- Cada tecnología debe tener justificación.
- No se agregan servicios por moda o disponibilidad.
- Cambios tecnológicos relevantes requieren análisis de impacto y aprobación.
- El perfil es específico del proyecto.

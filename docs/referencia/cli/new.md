# `ai-dev new`

Crea un documento desde su plantilla con el siguiente ID libre (p. ej. `ai-dev new PRD --title "..."`).

```
ai-dev new <tipo> [opciones]
```

**Argumentos**

| Argumento | Descripción |
|---|---|
| `tipo` | Tipo de documento o su prefijo: PRD, ADR, ARCHITECTURE, TD… |

**Opciones**

| Opción | Descripción |
|---|---|
| `--title <título>` (obligatoria) | Título del documento. |
| `--author <nombre>` | Autor (por defecto, git user.name). |

# `ai-dev context`

Genera el contexto mínimo suficiente de una tarea para entregárselo a cualquier agente.

```
ai-dev context <task-id> [opciones]
```

**Argumentos**

| Argumento | Descripción |
|---|---|
| `task-id` | ID de la tarea |

**Opciones**

| Opción | Descripción |
|---|---|
| `--out <archivo>` | Escribe el contexto en un archivo en lugar de la salida estándar. |

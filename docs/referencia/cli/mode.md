# `ai-dev mode`

Cambia el modo de rigor mientras el proyecto no tenga ninguna aprobación; después requiere una solicitud de cambio.

```
ai-dev mode <modo> [opciones]
```

**Argumentos**

| Argumento | Descripción |
|---|---|
| `modo` | LITE, STANDARD o CRITICAL |

**Opciones**

| Opción | Descripción |
|---|---|
| `--reason <texto>` (obligatoria) | Motivo del cambio (inclúyelo en el mensaje del commit). |

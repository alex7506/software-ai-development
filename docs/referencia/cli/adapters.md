# `ai-dev adapters`

Genera y comprueba los archivos de instrucciones de cada asistente de IA.

## `ai-dev adapters sync`

Genera o actualiza AGENTS.md, CLAUDE.md, GEMINI.md, reglas de Cursor e instrucciones de Copilot desde la metodología y .ai-dev/.

```
ai-dev adapters sync [opciones]
```

**Opciones**

| Opción | Descripción |
|---|---|
| `--force` | Sobrescribe también los bloques generados que se editaron a mano. |

## `ai-dev adapters status`

Muestra si cada archivo de adaptador existe y está al día.

```
ai-dev adapters status [opciones]
```

**Opciones**

| Opción | Descripción |
|---|---|
| `--json` | Salida en JSON. |

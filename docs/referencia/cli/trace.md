# `ai-dev trace`

Calcula la trazabilidad (requisitos → tareas → commits) y el estado de integridad.

```
ai-dev trace [opciones]
```

**Opciones**

| Opción | Descripción |
|---|---|
| `--git` | Incluye los commits y sus trailers `Task: TASK-NNN`. |
| `--json` | Salida en JSON. |

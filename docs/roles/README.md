# Roles

En un proyecto hay dos tipos de papel:

- **Roles que aprueban**: siempre los ocupa una persona. Ningún agente de IA puede ocuparlos.
- **Roles que ejecutan**: analista, arquitecto, desarrollador, tester, revisor… Los puede ocupar una persona o un agente de IA con los permisos adecuados.

Una misma persona puede tener varios roles. En proyectos LITE es normal que una sola persona lo haga todo; en STANDARD y CRITICAL, quien produce algo no puede aprobarlo.

| Guía | Para quién |
|---|---|
| [Responsable de producto](product-owner.md) | Quien decide qué se construye y aprueba lo que se publica |
| [Líder técnico](tech-lead.md) | Quien decide cómo se construye y aprueba arquitectura, tecnología y plan |
| [Calidad y seguridad](calidad-y-seguridad.md) | Quien valida que el producto cumple y es seguro |
| [Desarrollador](desarrollador.md) | Quien ejecuta tareas, sola o con asistentes de IA |

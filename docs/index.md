# Manual de usuario — Software AI Development

Software AI Development es una metodología, con su herramienta de línea de comandos `ai-dev`, para desarrollar software con ayuda de IA **sin perder el control**: cada decisión queda registrada, cada cambio se puede rastrear hasta un requisito y ninguna IA aprueba su propio trabajo.

Funciona con cualquier asistente de IA (Claude, Gemini, Copilot, Cursor, Codex…), cualquier lenguaje y cualquier nube.
